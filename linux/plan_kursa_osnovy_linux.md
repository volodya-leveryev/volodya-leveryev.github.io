# План курса «Основы ОС Linux»

7 лекций, 13 практических работ

Каждая лекция закрывает один пласт знаний, затем 1–2 практики сразу его закрепляют.

Курс постепенно продвигает студента по цепочке: «пользователь системы» → «пользователь с правами root» → «специалист, готовящий инфраструктуру» (веб-сервер, диски, контейнеры).

## Лекции

### Лекция 1. Введение в Linux
- История UNIX/Linux, философия «всё есть файл», дистрибутивы (Debian/RHEL-семейства) и их различия
- Способы установки и запуска: bare-metal, VM, WSL, облачный сервер
- Работа в терминале: shell, командная строка, автодополнение, история команд
- Справочная система: `man`, `--help`, `tldr`, поиск документации
- Обзор пакетных менеджеров (apt/dnf/pacman) — на уровне концепции, без деталей
- **Мотивационный блок**: карта курса — что дальше и зачем (какие темы важны для dev, какие для DevOps)

### Лекция 2. Файловая система и права доступа
- Иерархия файловой системы (FHS): `/etc`, `/var`, `/usr`, `/home` и др.
- Inode, типы файлов, жёсткие и символические ссылки
- Права доступа: `rwx`, восьмеричная нотация, `chmod`/`chown`/`chgrp`
- Специальные биты: SUID, SGID, sticky bit — зачем нужны, где используются
- Основы ACL (кратко, как расширение классических прав)
- Введение в обработку текста: `grep`, `sed`, `awk`, конвейеры и перенаправление (`|`, `>`, `>>`, `2>`)

### Лекция 3. Процессы, потоки и службы
- Процессы vs потоки, PID/PPID, состояния процесса, планировщик
- Сигналы (`kill`, `SIGTERM` vs `SIGKILL`), приоритеты (`nice`/`renice`)
- Инструменты мониторинга: `ps`, `top`/`htop`, `free`, `uptime`
- Init-системы: краткая история (SysV → systemd), unit-файлы
- Логирование: `journalctl`, `/var/log`, ротация логов

### Лекция 4. Пользователи, группы и безопасность
- Модель пользователей: UID/GID, `/etc/passwd`, `/etc/shadow`, `/etc/group`
- Создание/управление пользователями и группами, домашние директории, shell по умолчанию
- `sudo` vs `su`, файл `sudoers`, принцип наименьших привилегий
- Базовые принципы аутентификации (пароли, SSH-ключи) — подготовка к лекции про сети
- **Мотивационный блок**: PAM и более тонкая настройка политик — тема факультатива

### Лекция 5. Сети в Linux
- Базовая модель TCP/IP на практическом уровне (адреса, порты, протоколы)
- Инструменты диагностики: `ip`, `ss`/`netstat`, `ping`, `traceroute`, `curl`/`wget`
- SSH углублённо: ключи, агенты, туннелирование, конфиг `~/.ssh/config`
- Основы firewall (`ufw`/`firewalld` на уровне концепции)
- Веб-серверы как сетевой сервис: как клиент видит порт 80/443, что делает reverse proxy

### Лекция 6. Bash: скрипты и автоматизация
- Синтаксис shell-скриптов: переменные, условия, циклы, функции
- Работа с аргументами скрипта, exit-коды, обработка ошибок (`set -e`, `trap`)
- Полезные утилиты для скриптов: `xargs`, `find`, `cut`, `tr`
- Планирование задач: `cron`, `at`, systemd timers (кратко, как альтернатива cron)

### Лекция 7. Хранение данных и контейнеризация
- Диски, разделы, файловые системы (ext4/xfs), монтирование, `fstab`
- LVM: физические/виртуальные тома, группы томов, зачем нужен слой абстракции
- Введение в виртуализацию и контейнеризацию: чем контейнер отличается от VM
- Как это работает изнутри: namespaces и cgroups (без деталей реализации — на уровне «это то, что раньше называли модулями ядра и их использованием»)
- Docker: образы, слои, Dockerfile, реестры
- Docker Compose: оркестрация нескольких контейнеров как следующий логичный шаг
- **Мотивационный блок**: Kubernetes, продвинутый сетевой стек контейнеров, systemd в проде — темы факультатива по администрированию

## Практические работы (13 шт.)

| № | Название | Привязка к лекции | Ключевые задачи |
|---|---|---|---|
| П1 | Подключение к серверу по SSH и основы терминала | Л1 | Подключение по SSH, генерация ключей, базовая навигация |
| П2 | Работа в оболочке bash | Л1 | Навигация по ФС, история команд, переменные окружения, алиасы |
| П3 | Файловая система: права доступа и ссылки | Л2 | `chmod`/`chown`, спецбиты, hard/symlink, поиск файлов по атрибутам |
| П4 | Текстовые утилиты и обработка данных | Л2 | `grep`/`sed`/`awk`, конвейеры, обработка логов как практический кейс |
| П5 | Установка и управление ПО | Л1 | Пакетные менеджеры, репозитории, сборка из исходников (кратко) |
| П6 | Работа с процессами и потоками | Л3 | `ps`/`top`, управление приоритетами, сигналы, поиск «зависшего» процесса |
| П7 | Работа со службами | Л3 | systemd unit-файлы, старт/стоп/enable, чтение логов через `journalctl` |
| П8 | Работа с пользователями и группами | Л4 | Создание пользователей/групп, `sudo`, настройка SSH-доступа по ключу |
| П9 | Сетевая диагностика и настройка | Л5 | `ip`/`ss`, проверка доступности сервиса, базовая настройка firewall |
| П10 | Установка и настройка веб-серверов | Л5 | Nginx/Apache: конфигурация, виртуальные хосты, проверка через curl |
| П11 | Работа с дисками и LVM | Л7 | Разметка диска, создание ФС → расширение через LVM (единая работа в 2 частях) |
| П12 | Bash-скрипты и автоматизация задач | Л6 | Скрипт с аргументами и обработкой ошибок + автозапуск через cron |
| П13 | Контейнеризация: Docker и Docker Compose | Л7 | Сборка образа по Dockerfile → запуск multi-container приложения через Compose |

## Рекомендуемая последовательность (по неделям, при 13–14 неделях курса)

1. Л1 → П1
2. — → П2
3. Л2 → П3
4. — → П4
5. — → П5 *(установка ПО логично закрывает вводный блок)*
6. Л3 → П6
7. — → П7
8. Л4 → П8
9. Л5 → П9
10. — → П10
11. Л6 → П12 *(скрипты можно вставить раньше сетей, если нужно разгрузить конец курса)*
12. Л7 → П11
13. — → П13
14. Резерв / повторение / демонстрация мини-проекта (например, развернуть веб-приложение в Docker Compose с использованием пользователей, прав и скрипта деплоя — интегрирующая работа)

**Опционально** можно добавить в конце курса небольшой **итоговый проект**, который объединяет 4–5 практик (SSH → пользователь без root → права на директорию → скрипт деплоя → запуск в Docker Compose). Это не отдельная лекция/практика, а форма итогового контроля, которая хорошо показывает, кто из студентов готов к дальнейшему курсу «Администрирование ОС Linux».

## Связь с курсом «Администрированию ОС Linux»

Моменты которые, оставлены в основном курсе для стыковки с углубленным курсом:

- ACL и PAM (Л2, Л4) — упомянуты, но не разбираются подробно
- firewall и продвинутая сетевая настройка (Л5) — только базовый уровень
- namespaces/cgroups, модули ядра (Л7) — дана концепция, не реализация
- Kubernetes и продвинутый Compose/оркестрация (Л7) — явно вынесены за рамки
