# План курса «Методы и системы обработки больших данных»

**Магистратура, 14 недель, лекции + практика**

Структура курса: сначала фундамент (принципы Big Data, экосистема Hadoop), затем основной блок (Spark, включая прикладной ML), далее специализированные системы (BigQuery, ElasticSearch) и завершение — облачные ETL-конвейеры и финальный проект.

---

## Неделя 1. Введение в Big Data и архитектуры обработки

- Понятие Big Data: 5V (Volume, Velocity, Variety, Veracity, Value)
- Batch vs Stream processing, OLTP vs OLAP
- Обзор ландшафта: Hadoop, Spark, облачные DWH, NoSQL, поисковые системы
- Архитектурные паттерны: Lambda, Kappa, Data Lake vs Data Warehouse vs **Lakehouse**
- Слой хранения: объектные хранилища (**S3 / GCS / Azure Blob**) как основа современных data-платформ
- **Практика:** развёртывание учебного окружения (Docker/облачная песочница), знакомство с CLI

## Неделя 2. Экосистема Hadoop: основы

- HDFS: архитектура (NameNode, DataNode), репликация, отказоустойчивость
- YARN: планирование ресурсов
- MapReduce: модель программирования, жизненный цикл job'а
- **Практика:** работа с HDFS (загрузка, чтение файлов), запуск простого MapReduce-задания (word count)

## Неделя 3. Hadoop: расширенные темы

- Hive: HiveQL, метастор, партиционирование, бакетирование
- Краткий обзор HBase — колоночное NoSQL-хранилище поверх HDFS *(без глубокого погружения, для контраста с Hive)*
- Форматы хранения: Parquet, ORC, Avro — сравнение
- **Практика:** создание таблиц в Hive, партиционирование, запросы HiveQL к большому датасету

## Неделя 4. Введение в Apache Spark

- Почему Spark быстрее MapReduce: in-memory computing, DAG
- Архитектура: Driver, Executor, Cluster Manager
- RDD: создание, трансформации, действия, ленивые вычисления
- Партиционирование данных и его влияние на производительность
- **Практика:** установка PySpark, первые RDD-операции

## Неделя 5. PySpark: DataFrame API

- **От Pandas к PySpark** *(короткий вводный блок, 15–20 мин)*: синтаксическое сходство (select, filter/query, groupBy) vs принципиальные отличия — ленивые вычисления, распределённость, отсутствие произвольного индекса, immutability; типичная ошибка новичков — императивный стиль вместо распределённых операций; когда Pandas предпочтительнее Spark (данные помещаются в память)
- DataFrame vs RDD, Catalyst Optimizer, Tungsten
- Чтение/запись данных (CSV, JSON, Parquet)
- Основные операции: select, filter, groupBy, join, window functions
- **Практика:** ETL-пайплайн на PySpark DataFrame API с реальным датасетом

## Неделя 6. Spark SQL

- Spark SQL: SparkSession, временные представления (temp views)
- Оптимизация запросов, план выполнения (explain)
- Работа с UDF (User Defined Functions)
- Интеграция Spark SQL с Hive
- Обзорно: **Presto/Trino** как альтернативный подход к федеративным SQL-запросам поверх data lake
- **Практика:** написание аналитических SQL-запросов поверх больших таблиц, анализ query plan

## Неделя 7. Spark: производительность и tuning

- Shuffle, широковещательные (broadcast) join'ы
- Кэширование и персистентность (cache/persist)
- Skew data, солёные ключи (salting)
- **Delta Lake**: ACID-транзакции поверх файлов, эволюция Data Lake → Lakehouse
- Мониторинг через Spark UI
- Обзорно: **Databricks** как основная коммерческая платформа поверх Spark
- **Практика:** оптимизация «плохого» пайплайна, разбор проблем производительности

## Неделя 8. Основы ML-алгоритмов и Spark MLlib

- Прикладной минимум теории *(без вывода формул, на уровне интуиции)*: деревья решений, ансамбли — bagging vs boosting
- Pipeline API: Transformer, Estimator, Pipeline
- Feature engineering: VectorAssembler, StringIndexer, OneHotEncoder, масштабирование
- Модели: логистическая регрессия, деревья решений, случайный лес, **GBTClassifier/GBTRegressor**
- Распределённые версии градиентного бустинга: **XGBoost4J-Spark, SynapseML (LightGBM on Spark)** — как масштабировать алгоритмы, обычно работающие в памяти одной машины
- **Практика:** построение ML-пайплайна классификации на PySpark MLlib

## Неделя 9. Spark MLlib: продолжение + потоковая обработка

- Оценка моделей, кросс-валидация, подбор гиперпараметров (CrossValidator)
- Краткое введение в **Apache Kafka**: брокеры сообщений, топики, партиции *(как источник данных для стриминга)*
- Введение в Spark Structured Streaming: micro-batch, источники и приёмники
- **Практика:** потоковая обработка данных (например, из Kafka или файлового источника) с записью результатов

## Неделя 10. Google BigQuery

- Архитектура: serverless, разделение compute/storage, Dremel
- Синтаксис Standard SQL в BigQuery, партиционирование и кластеризация таблиц
- Стоимость запросов, оптимизация (сканирование колонок, slot-ы)
- BigQuery ML — краткий обзор
- Интеграция с внешними источниками (external tables, federated queries)
- **Практика:** загрузка датасета в BigQuery, написание аналитических запросов, оценка стоимости

## Неделя 11. ElasticSearch: основы

- Архитектура: узлы, шарды, реплики, инвертированный индекс
- Индексирование документов, mapping, типы данных
- Query DSL: match, term, bool-запросы
- Отличие полнотекстового поиска от аналитических СУБД
- **Практика:** создание индекса, загрузка документов, поисковые запросы

## Неделя 12. ElasticSearch: агрегации и стек ELK

- Агрегации: metric, bucket, вложенные агрегации
- Kibana для визуализации
- Logstash/Beats — сбор и доставка данных
- Использование Elasticsearch как аналитической системы (сравнение с BigQuery/Spark)
- **Практика:** построение дашборда в Kibana на основе агрегаций

## Неделя 13. ETL в облаках

- Принципы построения облачных ETL/ELT-пайплайнов
- Объектные хранилища как промежуточный слой пайплайна (S3 / GCS / Azure Blob)
- Обзор инструментов: Apache Airflow (оркестрация), Google Dataflow / Cloud Composer, AWS Glue, Azure Data Factory (обзорно)
- Паттерны интеграции: batch, событийные (event-driven) пайплайны
- Data Quality и мониторинг пайплайнов
- **Практика:** построение end-to-end пайплайна (например: источник → Spark/Dataflow трансформация → BigQuery → визуализация)

## Неделя 14. Итоговый проект и обзор курса

- Презентации итоговых проектов студентов (сквозной пайплайн с использованием минимум 2–3 изученных технологий)
- Разбор архитектурных решений, обратная связь
- Обзорная дискуссия: как выбирать инструмент под задачу (Hadoop vs Spark vs BigQuery vs ElasticSearch)
- Итоговая аттестация
